Settings

AUTO_SHOW_DELAY_MS
Milliseconds before the word gate opens. 1000 = 1 second, 300000 = 5 minutes.
SOUND_VOLUME x2.0
Playback gain relative to the Windows master volume. 2.0 = twice as loud.
START_WITH_WINDOWS
Adds an entry to the current user's registry Run key (no admin rights needed). If the exe is moved or renamed, the entry is updated the next time Kotoba Lock starts.
IGNORE_WORDS
One word per line, or separate with commas. These words will never be shown.
